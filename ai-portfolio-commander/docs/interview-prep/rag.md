# RAG Interview Questions

## Q1. What is RAG?

### Senior Answer

Retrieval-Augmented Generation combines:

- Retrieval
- Context Injection
- LLM Generation

to provide grounded and up-to-date responses.

---

## Q2. Why use RAG instead of fine-tuning?

### Senior Answer

RAG:

- Easier to update
- Lower cost
- Better traceability
- Supports citations

Fine-tuning changes model behavior.

RAG changes knowledge access.

---

## Q3. What are embeddings?

### Senior Answer

Embeddings are numerical vector representations of data that capture semantic meaning.
