# FastAPI Interview Questions

## Q1. Why use FastAPI?

### Junior Answer

To build APIs.

### Mid-Level Answer

FastAPI allows rapid API development with validation.

### Senior Answer

FastAPI provides:

- Type safety
- Automatic validation
- OpenAPI documentation
- Async support
- High performance

It reduces development effort while improving reliability.

---

## Q2. What is an API?

### Junior Answer

A way to communicate between systems.

### Senior Answer

An API defines a contract that allows systems to exchange information in a predictable manner.

---

## Q3. What is a REST API?

### Senior Answer

REST is an architectural style that uses HTTP methods and stateless communication to manipulate resources.

Methods:

GET
POST
PUT
PATCH
DELETE

---

## Q4. Why GET instead of POST?

### Senior Answer

GET should be used when retrieving data because it is idempotent and does not modify server state.
