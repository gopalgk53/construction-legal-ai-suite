# Agentic AI Interview Questions

## Q1. What is an AI Agent?

### Senior Answer

An agent is an AI system that can:

- Reason
- Plan
- Use tools
- Execute actions
- Maintain state

to achieve goals.

---

## Q2. What is LangGraph?

### Senior Answer

LangGraph provides stateful workflows for agent systems.

Benefits:

- State management
- Conditional routing
- Human approval steps
- Durable execution

---

## Q3. What is Human-in-the-Loop?

### Senior Answer

Human-in-the-Loop introduces human review before high-risk actions are executed.
