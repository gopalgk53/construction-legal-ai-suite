# Engineering Mindset

## Q1. What is the difference between programming and software engineering?

### Senior Answer

Programming focuses on writing code.

Software engineering includes:

- Requirements
- Design
- Implementation
- Testing
- Deployment
- Monitoring
- Maintenance

Software engineering is about building reliable systems.

---

## Q2. What makes a Senior Engineer?

### Senior Answer

A senior engineer demonstrates:

- Ownership
- Architecture thinking
- Tradeoff analysis
- Debugging
- Mentorship
- Delivery
- System thinking

Seniority is not measured by years alone.

---

## Q3. What is technical debt?

### Senior Answer

Technical debt refers to shortcuts taken today that increase future maintenance costs.

Examples:

- Hardcoded values
- Lack of tests
- Poor architecture
- Duplicate code
